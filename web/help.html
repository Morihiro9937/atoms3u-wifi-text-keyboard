输入一篇文字

  1. 主页每秒统一同步一次指令、正文保存和打印状态。打印后显示绿色进度条及预计剩余时间（到秒），暂停时保留，完成后保留100%满条；失联时冻结并变灰。剩余时间按剩余字数估算，实际速度需在目标电脑验证。
  2. 在主页面粘贴已经人工核对的正文，停止编辑约 1.5～2.5 秒后自动保存。左侧黄灯表示尚未保存完，绿灯表示已写入断电存储。
  3. 先在 Windows 记事本中测试。VUC 从微软拼音中文状态开始；ENG、GBK 从英文状态开始。GBK 还需开启 Num Lock；确认光标位置。
  4. 点击网页“打印”，它会先保存最新版，再按设置中的倒计时开始输入。也可以在绿灯时短按实体按钮。
  5. 输入期间不要操作真实键盘、鼠标或切换窗口。
  6. 打印中点击“暂停”会等当前字完整输入后停下；点击“继续”从暂停处接着输入。点击“停止”或长按实体按钮约 1 秒会终止本次打印。
  7. 输入完成后逐字核对；确认无误后再用于目标系统。

实体指示灯

黄灯：编辑内容尚未完全保存 待机绿灯常亮：手机网页与设备互联正常 待机红0.4秒、绿1.6秒循环：约6秒未收到网页互联心跳 倒计时：绿灯慢闪 打印时：VUC仅按c、GBK仅按小键盘1、ENG仅按E/e时亮绿灯，键释放即熄灭 蓝灯：已暂停，可继续或停止 红灯常亮：本次打印已停止；再次修改并保存正文后恢复绿灯 红灯：设备发生错误

数据与设置

  • VUC 模式输入所有可打印字符；ENG 模式直接输入英文键盘上的 ASCII 字符，中文等非 ASCII 字符会跳过。
  • GBK 使用 Alt＋数字小键盘，不使用 VUC。中文显示取决于 Windows 系统编码和目标软件；不保证所有软件兼容。请先用短文本验证。
  • GBK 遇到无法编码的字符会拒绝整篇打印并提示位置，不会悄悄跳过。暂停、停止会等当前 Alt 编码完整结束再执行。
  • GBK、ENG、VUC 的速度分别保存，断电后仍会保留。
  • Wi-Fi名称、密码和本地登录地址可在“设置 → Wi-Fi设置”中修改。登录地址必须使用 http://名称.local；备用地址 http://192.168.4.1 固定不可修改。
  • 输入指示灯和待机指示灯可在设置中分别关闭，选项断电后保留。
  • GBK 可分别设置 Alt 按下后间隔、数字按下时间、数字间隔、Alt 松开前间隔和字间间隔。
  • 正文会写入设备断电存储；拔掉设备后再次上电，正文仍然存在。新内容覆盖旧正文，不保存多篇历史。
  • “清空”会删除当前正文；但普通闪存删除不能保证旧数据不可恢复。请勿把它当作安全擦除。
  • 正文和速度设置都会在断电后保留。建议避免保存含患者身份信息的正文。
  • 正文上限为 32768 字节，超过上限会拒绝保存，不会截断。

常见问题

  • 出现原始vuc编码：确认Windows微软拼音处于中文状态。
  • 出现漏字、错字或乱码：适当增加间隔时间、空格前间隔或空格后间隔。
  • 本地域名打不开：确认仍连接karute Wi-Fi并关闭VPN，然后使用固定备用地址 http://192.168.4.1。
